GUÍA OPCIONAL

La radio, también
en Discord.

Discord es la interfaz principal prevista para el proyecto. La web es una ayuda adicional para la evaluación: puedes continuar escuchando sin crear una cuenta de desarrollador ni configurar un bot.

Continuar con la evaluación web →
01

Crea una aplicación

Abre el Discord Developer Portal ↗, inicia sesión y pulsa New Application. Ponle un nombre, por ejemplo CC-DASRadio.

En General Information, copia Application ID: corresponde a DISCORD_CLIENT_ID.

02

Obtén el token del bot

En Bot → Token → Reset Token, genera el token y cópialo directamente al archivo .env local, en DISCORD_TOKEN. El Client Secret de OAuth2 es otra credencial.

Trata el token como una contraseña: no lo pegues en esta web, en el chat ni en Git. Si se expone, regénéralo en Discord. Esta página no solicita ni guarda credenciales.

Los comandos /radio start, /radio stop y /radio now funcionan sin activar los Privileged Gateway Intents. El campo Interactions Endpoint URL se deja vacío: este bot recibe las interacciones mediante su conexión a Discord.

03

Invítalo a tu servidor de pruebas

En Installation, habilita Guild Install y selecciona Discord Provided Link. En los ajustes de Guild Install, añade los scopes bot y applications.commands.

Concede View Channels, Send Messages, Connect y Speak para la prueba. No hace falta Administrator. Abre el enlace de instalación y selecciona un servidor que puedas gestionar.

04

Completa la configuración local

En Discord, activa Ajustes de usuario → Avanzado → Modo desarrollador. Haz clic derecho en el icono de tu servidor y selecciona Copiar ID del servidor. Ese valor es DISCORD_GUILD_ID; no es el ID del canal.

Edita únicamente los campos del bot en tu .env existente. Conserva las claves internas de PostgreSQL y la API:

DISCORD_TOKEN=token_del_bot
DISCORD_CLIENT_ID=id_de_la_aplicacion
DISCORD_GUILD_ID=id_del_servidor
05

Registra el comando y arranca

En una terminal, desde la carpeta CC-DASRadio:

docker compose build discord-service
docker compose run --rm discord-service node dist/register-commands.js
./scripts/start.sh --discord

En Windows, sustituye la última línea por:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -WithDiscord

El bot registra los comandos globalmente al conectar y los actualiza si cambian. Sirven en todos los servidores donde lo instales; no tienes que cambiar DISCORD_GUILD_ID para cada uno. Después escribe /radio now en un canal de texto. Para escuchar, entra en un canal de voz del servidor y ejecuta /radio start. Usa /radio stop para salir. Web y Discord comparten la emisora y su posición actual.

06

Si el bot no funciona, puedes continuar

Consulta sus mensajes con docker compose logs --tail=30 discord-service. Si no aparece el comando, comprueba que la aplicación esté instalada con applications.commands, revisa el registro global en los logs y recarga Discord. Si no conecta, revisa el token y el acceso a Internet.

Para evaluar sin Discord, ejecuta ./scripts/start.sh --web-only, o el script PowerShell con -WebOnly. Sin opciones, el lanzador incluye el bot si detecta el token y los dos IDs completos. La web, la API y PostgreSQL funcionan de forma independiente del bot.
